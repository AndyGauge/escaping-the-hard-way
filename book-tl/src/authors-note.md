# Tala ng May-Akda

Gumagamit ang librong ito ng tuwirang pananalita tungkol sa karahasan, pagpatay, tortyur, adiksyon, at kamatayan.  Hindi ko pinalalambot ang mga salitang ito.  Hindi ko tatawagin ang pagpatay na "pag-unalive."  Hindi ko tatawagin ang tortyur na "pinahusay na interogasyon."  Hindi ko tatawagin ang lugar kung saan pinapadala ang mga tao para mamatay na "ang farm" maliban kung ipapakita ko sa iyo kung paano ginamit ang salitang iyon para itago ang totoong nangyayari.

Ang normalisasyon ng karahasan ay nagsisimula sa normalisasyon ng mga salitang ginagamit natin para ilarawan ito.  Kapag ginawa nating sapat na cute ang kamatayan para sa algorithm, ginagawa natin itong sapat na maliit para balewalain.  Nakita kong natuto ang isang buong bansa na pag-usapan ang malawakang pagpatay tulad ng pag-uusap tungkol sa panahon.  Nakikita kong nagsisimulang gawin ng sarili kong bansa ang ganoon din.

Maaaring hindi ganap na tama ang pagkakasunod-sunod ng mga pangyayari sa librong ito.  Sampung araw ang biyahe at parang isang iglap lang.  Hindi ko naisipang i-record ito noon dahil hindi ko pa naiintindihan ang epekto nito.  Nagsulat ako ng blog araw-araw habang nangyayari ito sa totoong oras, pero nawala na ang rekord na iyon.  Ang natitira ay alaala, mga litrato, at ang bigat ng dinala kong pauwi.  Totoo ang mga pangyayari.  Totoo ang mga tao.  Maaaring magbago ang pagkakasunod-sunod dahil ganoon ang paggana ng alaala — nag-aayos ito ayon sa epekto, hindi ayon sa kalendaryo.  Ang mga bagay na pinakamatinding tumama ang pinakamalinaw.  Ang natitira ay binuo ko nang pinaka-tapat na kaya ko.

Ang pagtakas namin sa ang mahirap na paraan ang naghanda sa amin para harapin itong muli.

Ang librong ito ay hindi ligtas.  Nangyari ang mga bagay na nasa loob nito.  Ang pananalitang ginagamit ko para ilarawan ang mga ito ay ang pananalitang nararapat sa kanila.  Kung mahirap itong basahin, ganoon naman talaga dapat.  Mahirap itong isabuhay.
